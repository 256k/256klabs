### Times of change

I can't believe that the last time I wrote in this blog feed was in 2024... how time flies.

Not going to bother to really talk about why or what happened since then since so much has changed between 2024 and 2026.

I don't even really know why I'm writing this post now as I haven't really thought about anything pertinent to say yet.

I do feel like i needed to revive this blog. I've have a lot of thoughts and opinions on the goings on in life and the world and I need to share them.

I also want to start exploring some more creative projects and I would like to document my findings along the way as well.

I don't know if anyone is actually subscribed to this RSS feed or not, but if you are, thank you for having an interest in my work and / or what I think.

I also feel like I would like to migrate this website into another self rolled solution. Currently it is a custom jekyll template that generates a static website based on the markdown files i feed it and the templates that it has. Part of me wants to build my own online version where I can simply just type some markdown or even just some vanilla text into a textarea on a website and have it publish it for me. The other thought is having the website entirely generated by some emacs code. write it all in org mode and have emacs convert the org text into the proper html with the proper templates and styles. I've only ever done this conversion once but it was a very minimal test and the results was a bit ugly. Something charming though about the idea of having the website be entirely just a bunch of org files. The third option is to create my own static site generator instead of this jekyll one using another language and do everything from scratch and just publish a static html website to a webhost. both this or the other emacs solution would mean I would no longer require relying on a CI pipeline that builds and publishes my website today (sadly, Github).

For now, the jekyll blog remains. and perhaps I could slowly start to integrate it into emacs without it actually being completely handled by emacs. I wonder if it can convert org files too? hmmmm

I'm not going to be complaining about the world or work or life or anything else. I want to stay away from all of that and hopefully share some fun projects that I have in the works as well as try to document some older projects that maybe have never seen the light of day or have been poorly documented and forgotten.

Stay human.
Peace.
